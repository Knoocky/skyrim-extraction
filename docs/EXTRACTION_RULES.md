# Серверные правила выхода

ExtractionPolicy (src/extraction-policy.ts) экспортируется в библиотеке SkyMP. Это чистый компонент для игрового адаптера; настоящий мир ещё не подключён. Демонстрационная кнопка выхода сохраняет явно обозначенную имитацию.

Зоны задаёт сервер: worldId, cellId, центр, радиус, время удержания и доступность always/day/night. FormID/координаты реальных зон пока не выбраны. Ночь: [20:00, 06:00), день: [06:00, 20:00).

Адаптер подаёт последовательные авторитетные наблюдения: личность, экспедиция, подключение, ячейка, координаты, жизнь/бой/соединение, игровой час, монотонное время наблюдения и счётчик полученного урона. Используется серверный монотонный clock, по умолчанию performance.now. Нельзя передавать сюда клиентский JSON с заявлениями о здоровье/позиции.

Таймер начинается только внутри правильной зоны. Смерть, бой, отключение, выход за радиус, смена ячейки/мира, закрытие выхода, неверные данные отменяют удержание. Урон, новое подключение/экспедиция и пропуск наблюдений начинают отсчёт заново. Старые/повторные/будущие наблюдения не продвигают время. Перезапуск процесса консервативно теряет незавершённый отсчёт.

READY не является долговечным разрешением: непосредственно перед командой extract адаптер должен получить свежее наблюдение, проверить текущие expeditionId/connectionId, заблокировать конкурентные действия и только затем передать worldApproved. После смерти/отключения/успешной экстракции вызвать cancel(playerId); при восстановлении мира clear(). Не сохранять READY в клиенте и не использовать его после перемещения.

Проверки покрывают точную границу времени/радиуса, сброс от боя/урона/переподключения, пропуски и повторы наблюдений, время суток и неизвестные значения. Это не проверка достоверности SkyMP-позиций и не реализация полного античита. Ночные модификаторы боевых характеристик/спавна ещё не подключены.
