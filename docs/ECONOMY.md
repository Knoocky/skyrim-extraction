# Экономика 0.4 / баланс 1 / схема 3

## Данные и доверие

Неизменяемый серверный каталог src/economy.mjs задаёт офферы, контракты и улучшения. Клиент передаёт только идентификатор предложения/контракта/предмета и количество. Цена, шаблон выдачи, опыт и награда не принимаются из запроса. UI показывает ту же версию каталога; решение всегда за сервером.

Новые операции протокола 1: buy(offerId, quantity), sell(itemId, quantity), upgrade(moduleId, expectedLevel), learnSkill(skillId, expectedRank), acceptContract(contractId), turnInContract(contractId, itemIds). Все требуют актуального connectionId, запрещены при активной экспедиции. Версия протокола прежняя: изменения аддитивны, старый сервер отклонит неизвестную операцию. Игровой адаптер дополнительно обязан подтвердить нахождение в убежище.

Все операции используют общий механизм атомарных квитанций и outbox. expectedLevel/expectedRank предотвращают случайную покупку следующего уровня новым запросом со старого экрана. При неизвестном исходе UI блокирует новые действия и повторяет тот же requestId. Подтверждённый отказ позволяет исправить действие; ошибка после коммита не считается отказом.

## Начальные правила

| Объект | Правило |
|---|---|
| Кошелёк | Начальное золото 0; сохраняется после смерти; предел 1 млрд |
| Торговля | 5 офферов, 3 роли; бесконечный базовый ассортимент; продажа дешевле покупки даже при максимальной скидке |
| Опыт | 10 за единицу впервые извлечённой мировой добычи; 100/100/150 за три контракта |
| Уровень | 1 + floor(xp / 100), без влияния на боевые характеристики |
| Переговоры | До 3 рангов; 1 очко за ранг; +5% золота новых контрактов за ранг |
| Мастерская | 3 уровня, цена 100/200/400; скидка 5% за уровень, округление цены вверх |
| Архив | 1 уровень за 100; открывает третий контракт |
| Контракты | Лекарю 3 зелья → серебряное кольцо → двемерская реликвия; однократная цепочка |

Условия и итоговая награда фиксируются при принятии контракта. Смена баланса не меняет уже принятое поручение. Сдача принимает только собственные подходящие предметы в схроне, отнимает точное количество, сохраняет остаток стека. Покупные предметы допустимы для начальных поручений; их конечность ограничивает прибыль. Повторяемые контракты, конечные запасы и торговая репутация не реализованы.

Покупные и стартовые вещи не дают опыт экстракции. Маркер первого извлечения принадлежит предмету, а не игроку: смерть/чужой подбор после первого выхода не дают повторной награды. Split/merge доступны только в схроне, куда вещь попадает после отметки об извлечении. Миграция не присваивает происхождение старым предметам: они не дают новый опыт. Закрытие мира удаляет лут с его маркерами.

## Миграция и ограничения

Схема 2 → 3 добавляет progression, player_contracts и loot_provenance, сохраняет активные экспедиции, UUID, databaseId и квитанции, обновляет полную проекцию. Старым игрокам назначается нулевой кошелёк/опыт без ретроактивных наград. Копия до обновления обязательна для отката; новое ядро продолжает поддерживать миграции с 0/1.

Пока нет аварийной бесплатной выдачи после полного разорения, ограничений вместимости, материалов для строительства, опыта от боя и полных деревьев навыков. Баланс предназначен для проверки цикла без игры. Настройка доходности, PvP и длительности прогрессии требует игрового тестирования.
