# Skyrim Extraction — разработка 0.4

Постоянное ядро extraction-режима, закрытый HTTP API, интерфейс схрона и экспериментальный адаптер SkyMP.
**Это ещё не устанавливаемый и проверенный в Skyrim мод.** Доступный без игры стенд воспроизводит экономику двух персонажей; бой и игровой мир не симулирует.

## Запуск без Skyrim

Нужен Node.js 24.19.0. В папке репозитория:

```sh
npm ci
npm run typecheck
npm test
npm run demo:ui
```

Откройте адрес, напечатанный последней командой. Выберите снаряжение, войдите в экспедицию, подберите добычу и выйдите. Кнопка смерти оставляет вещи второму персонажу; переключение Alice/Bob позволяет забрать их и вынести. Зелья списываются, но лечение не реализовано. Стенд использует настоящее ядро через HTTP и временную SQLite; при закрытии данные удаляются. Это демонстрация, не игровой сервер.

`npm run demo` запускает консольный сценарий. `npm run build` создаёт React UI в `dist/ui` и библиотеку адаптера `dist/skymp-adapter.cjs`. Библиотека сама не подключает игроков и не запускает SkyMP.

## Постоянный сервис

```sh
npm run init:server
npm start
```

Создаётся локальный серверный ключ; повторная инициализация существующий ключ не заменяет. По умолчанию сервис слушает `127.0.0.1:8787`, база — `data/core.sqlite`. Настройки: `EXTRACTION_DB`, `EXTRACTION_TOKEN_FILE`, `EXTRACTION_PORT`, `EXTRACTION_BIND`. Ключ предназначен исключительно доверенному серверному адаптеру. Не помещайте его в UI, клиентский мод или репозиторий. API нельзя открывать игровым клиентам.

```sh
npm run backup -- data/core.sqlite data/backup-001.sqlite
```

Резервная копия включает зафиксированные WAL-транзакции и проверяется на целостность; существующий файл не перезаписывается. Перед обновлением сохраните копию. Схемы 0/1/2 автоматически мигрируют в 3 с сохранением UUID и квитанций. Для отката остановите ядро и адаптер, восстановите согласованную резервную копию и повторно сверяйте игровой мир до разрешения действий. Возвращать старую базу при работающем мире нельзя.

## Реализовано

- Схрон, выбор экипировки, общий лут, смерть с потерей вещей, чужой подбор и экстракция.
- Стеки зелий, split/merge, авторизованное списание; UUID экземпляров и транзакционные квитанции.
- Постоянный мир и отдельные экспедиции: повторный вход не сбрасывает другого игрока.
- Поколения подключений; старые команды подключения и события прошлой экспедиции отклоняются.
- Ревизии и устойчивая проекция полного состояния, атомарные с экономическими изменениями.
- Мост: блокировка взаимодействий → применение и сверка → подтверждение → разрешение действий. Ошибка оставляет блокировку.
- Частный HTTP/JSON протокол с серверным ключом, строгой валидацией и запретом браузерного доступа.
- React/TypeScript UI, HTTP-демонстрация двух персонажей, резервные копии, Windows/Linux CI.
- Экспериментальный SkyMP-порт замены инвентаря и блокировки стандартных экономических действий.

SQLite — источник постоянного имущества. Проекция заменяет состояние; квитанцию старого pickup нельзя превращать в повторный AddItem. Полный снимок может объединять несколько ревизий: он не является очередью однократных эффектов лечения/награды. Подтверждение серверного инвентаря ещё не доказывает синхронизацию настоящего клиента.

## Экономика и прогрессия 0.4

В том же стенде доступны три торговца, цепочка из трёх контрактов, золото, опыт, навык переговоров, мастерская и архив. Можно вынести зелья, сдать припасы лекарю, получить награду, изучить переговоры, выполнить заказ на серебро и открыть архив для последнего контракта. Покупки, продажи и улучшения доступны вне активной экспедиции.

Цены и награды задаёт сервер. Контракт сохраняет условия при принятии; сдача расходует только требуемое количество из указанных стеков. Новый requestId не позволяет повторно получить награду завершённого контракта. Мастерская снижает цены покупки на 5% за уровень. Переговоры увеличивают золото новых контрактов на 5% за ранг. Каждые 100 опыта дают очко навыка. Первое извлечение новой мировой добычи даёт 10 опыта за единицу; повторный вынос, передача другому игроку и смерть не возобновляют награду. Старая добыча после миграции не получает опыт задним числом.

Это начальный проверяемый баланс, не полный контент 1.0: пока 5 шаблонов, 3 контракта, 2 улучшения, 1 навык. Не добавлены финальная сюжетная цепочка, 20–30 контрактов, 6 модулей и игровой эффект навыков боя. [Правила экономики](docs/ECONOMY.md).

## Что остаётся до рабочей версии

Игровая авторизация, проверка позиций/боя, создание контейнеров в мире, соответствие UUID и FormID, восстановление клиентов, лечение, уязвимый персонаж при отключении, игровой контент и упаковка ещё требуют реализации и проверки. Простой порт поддерживает только базовые предметы без зачарований и дополнительных свойств. Не используйте его как готовую защиту PvP.

При аудите SkyMP обнаружен обход запрета расхода зелья; подготовлен C++ патч с тестом, его компиляция перенесена в GitHub Actions; результаты — в PROGRESS.md. Два настоящих клиента ещё не запускались. G1 не пройден, версия 1.0 не объявлена.
