# Компоненты дистрибутива

Собственный код — MIT, см. LICENSE. UI содержит React, React DOM и Scheduler (MIT); полные уведомления включены в licenses/. Версии зафиксированы package-lock.json. esbuild, TypeScript и Playwright — инструменты разработки, их исполняемые файлы не входят в .sxe.gz. Установленные через npm инструменты сохраняют собственные лицензии в node_modules.

Node.js, SkyMP, Skyrim Platform, Skyrim, SKSE и игровые ресурсы **не входят** в архив. Их установка и условия распространения рассматриваются отдельно. Патч SkyMP и его исходный репозиторий не упаковываются этим скриптом. Наличие адаптерного интерфейса не означает совместимость с непроверенным модлистом.
